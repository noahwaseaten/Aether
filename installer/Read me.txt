Aether: a Monster Hunter: World overlay

Install
  1. Extract this zip somewhere (right-click > Extract All).
  2. Run "Install Aether.cmd".
     If Windows says "Windows protected your PC", click More info > Run anyway.
     Aether isn't code-signed, which is why Windows asks.
  3. Aether starts and adds Start Menu and Desktop shortcuts. Start it before or after the game.

Use
  Click "Edit layout" in the Aether window, or hold Left Alt in game, to move widgets.
  Drag to move, scroll to resize, double-click to reset the size, hold Shift to turn off snapping.
  F1 hides the overlay while held.

Updates
  Aether checks for a new version every time it starts and installs it by itself.

Party sync
  Only the host's game knows exact part HP and ailment buildup, and the game doesn't count damage on
  expeditions. If everyone in your party runs Aether with "Share data with your party" on (it is by
  default), you all see the host's numbers. You can turn it off in Settings.

Uninstall
  Run "Uninstall Aether.cmd" in %LOCALAPPDATA%\Aether.
